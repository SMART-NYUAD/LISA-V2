# Archive Directory

This directory contains historical versions and experimental code from the development of LISA.

## Contents

- Early versions of the navigation and camera system
- Experimental implementations
- Test scripts and utilities
- Deprecated system prompts and configurations

## Note

These files are kept for reference purposes only. For current, working implementations, please refer to the main project directory.

The active scripts are:
- `lisa_api_kb.py` - API backend with keyboard input
- `lisa_local_kb.py` - Local Ollama with keyboard input  
- `lisa_api_clicker.py` - API backend with clicker/ASR input
